🗺️ 카카오맵 연결이 필요해요

  1. developers.kakao.com 에 카카오 계정으로 로그인
  2. 내 애플리케이션 → 애플리케이션 추가하기 (이름은 아무거나)
  3. 앱 키 메뉴에서 JavaScript 키를 복사
  4. 플랫폼 → Web 의 사이트 도메인에 http://localhost:8080 등록
  5. 카카오맵 사용 설정 메뉴가 보이면 ON으로 켜기
  6. 이 파일(index.html) 아래쪽 KAKAO_APP_KEY = '' 따옴표 안에 키 붙여넣기
  7. 파일을 더블클릭하지 말고 http://localhost:8080 주소로 열기
지도 없이도 왼쪽 목록은 그대로 볼 수 있어요.
